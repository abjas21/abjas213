# abjas213
Растровый файл (PNG, JPG, WebP) используется для обложки, потому что это сложная иллюстрация с множеством мелких деталей, плавных цветовых переходов, светотени и текстур (листья, горшки, освещение). Растровая графика состоит из сетки пикселей и лучше всего передает художественные изображения и фотографии.
• Судя по вашей иллюстрации из GigaChat, вы выбрали пару зелёный и красный (или терракотовый/красно-оранжевый).
•  На учебном цветовом круге Иттена эти цвета расположены строго напротив друг друга — такая пара называется дополнительными (комплементарными). Сочетание противоположных цветов создает максимальный контраст и хорошо выделяет акцентную кнопку на фоне основной иллюстрации.
Для акцентного терракотово-красного оттенка с вашей картинки запись выглядит так:
• В HEX: #B85A4B
• В RGB: rgb(184, 90, 75)
• В HSL: hsl(8, 43%, 51%)
(Если в CSS-коде вашей кнопки задан другой точный оттенок красного или зеленого, подставьте сюда свои цифры из файла стилей).
• Модель для полноцветной печати: используется цветовая модель CMYK (Cyan — голубой, Magenta — пурпурный, Yellow — жёлтый, Key/Black — чёрный).
Если вы уже прописали цвет кнопки в своем файле стилей, можете написать его код (например, из CSS) — я переведу в HEX, RGB и HSL именно ваш точный оттенок, чтобы ответ на третий вопрос на 100 % совпал с вашим проектом.
